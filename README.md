# Week-6: Open Source Collaboration Project

## 1. 프로젝트 소개

Week-6 프로젝트는 오픈소스 소프트웨어(OSS)의 기본 구조와 협업 방식을 학습하기 위한 실습 프로젝트입니다.

GitHub를 활용하여 공개 저장소를 운영하고, 라이선스 및 기여 규칙을 정의하며, 오픈소스 커뮤니티 운영에 필요한 문서를 관리하는 것을 목표로 합니다.

## 2. 프로젝트 목표

- Public GitHub 저장소 운영
- 오픈소스 라이선스 적용
- README 및 기여 가이드 작성
- 커뮤니티 행동 강령 수립
- 주요 OSS 라이선스 비교 분석
- 조직 내부의 Inner Source 도입 방안 설계

## 3. 프로젝트 구조

```text
week-6/
├── README.md
├── LICENSE
├── CONTRIBUTING.md
├── CODE_OF_CONDUCT.md
└── docs/
    ├── LICENSE_COMPARISON.md
    └── INNER_SOURCE_ROADMAP.md
```

위 구조는 최종 완성 목표이며, 일부 문서는 작업 과정에서 순차적으로 추가됩니다.

## 4. 시작하기 (Getting Started)

### 요구 환경

- GitHub 계정
- Git 또는 GitHub 웹 브라우저 환경
- Markdown 문서 편집 도구

### 저장소 복제

```bash
git clone https://github.com/sodlfxhzms923/week-6.git
cd week-6
```

현재 프로젝트는 OSS 협업과 문서 관리 실습을 중심으로 구성되어 있으며, 별도의 프로그램 설치나 실행 환경은 필요하지 않습니다.

## 5. 기여 방법 (Contributing)

누구나 프로젝트의 문서 개선과 협업 방식에 대한 의견을 제안할 수 있습니다.

기여 절차는 다음과 같습니다.

1. 저장소를 Fork합니다.
2. 새로운 브랜치를 생성합니다.
3. 문서 또는 프로젝트 내용을 수정합니다.
4. 변경 사항을 커밋합니다.
5. Pull Request를 생성합니다.
6. 리뷰를 통해 피드백을 반영합니다.

자세한 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.

## 6. 커뮤니티 행동 강령

프로젝트 참여자는 서로를 존중하며 건설적인 의견을 공유해야 합니다.

차별, 괴롭힘, 모욕적인 표현을 지양하고 안전한 협업 환경을 유지합니다.

자세한 내용은 [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)를 참고하세요.

## 7. 라이선스

본 프로젝트는 MIT License를 적용합니다.

MIT License는 저작권 및 라이선스 고지 등의 조건을 준수하는 범위에서 사용, 수정, 배포, 상업적 이용을 허용합니다.

자세한 사항은 [LICENSE](LICENSE) 파일을 확인하세요.

추가적인 라이선스 비교 및 선택 근거는 [LICENSE_COMPARISON.md](docs/LICENSE_COMPARISON.md)에 정리합니다.

## 8. Inner Source

Inner Source는 조직 내부에서 오픈소스 개발 방식과 협업 문화를 활용하는 접근 방식입니다.

본 프로젝트에서는 코드 공유, 리뷰, 문서화, 공동 유지보수 등을 중심으로 조직 내부 도입 계획을 수립합니다.

자세한 내용은 [INNER_SOURCE_ROADMAP.md](docs/INNER_SOURCE_ROADMAP.md)를 참고하세요.
